# Student Performance Dashboard – Power BI Project

## Overview

This project is an interactive Power BI dashboard designed to analyze student academic performance, attendance, and behavior across subjects and terms using data modeling, DAX, and visual storytelling.

## Dataset Used

* Students.csv
* Scores.csv
* Attendance.csv
* Behavior.csv

## Features

* Data cleaning and relationship modeling
* DAX measures for:

  * Average Score
  * Attendance %
  * Behavior Count
  * Performance Category
* Interactive visualizations:

  * Bar Chart
  * Line Chart
  * Donut Chart
  * KPI Cards
  * Conditional formatted tables
* Slicers and drillthrough pages
* Bookmark navigation and tooltips

## Tools Used

* Power BI Desktop
* Power Query
* DAX
* Data Modeling

## Analysis Performed

* Student performance by subject and class
* Attendance tracking
* Behavior analysis
* Academic trend analysis by term

## Deliverables

* `.pbix` Power BI dashboard file
* Interactive analytical reports
* DAX calculations and KPIs

## Conclusion

This project demonstrates practical Power BI dashboard development skills including ETL, data modeling, DAX calculations, interactive reporting, and educational performance analytics.
